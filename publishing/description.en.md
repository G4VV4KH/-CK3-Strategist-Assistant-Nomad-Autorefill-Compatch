# [compatch] SA + NA

**Version 0.1.0 · Targets CK3 1.21.0.3**

Use [Strategist Assistant](https://steamcommunity.com/sharedfiles/filedetails/?id=3827659479) and [Nomad Autorefill](https://steamcommunity.com/sharedfiles/filedetails/?id=3814793283) together in the Military window. Plan armies, recruitment and wars, then choose herd or gold for automatic nomadic Men-at-Arms reinforcement in the same window.

## Compatibility and load order

Enable Strategist Assistant 0.1.2 → Nomad Autorefill 0.1.3 → [compatch] SA + NA. Nomadic reinforcement requires Khans of the Steppe.

Both parent mods replace `gui/window_military.gui`. This patch combines their controls in one file. Another mod that replaces this same file needs a separate compatibility check. Removing this patch returns control of the Military window to whichever parent loads last.
